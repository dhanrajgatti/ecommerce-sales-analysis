# ecommerce-sales-analysis
Built an automated data pipeline and dashboard to track monthly sales performance, regional revenue trends, and customer purchasing behavior.

SQL Data Extraction: Wrote optimized SQL queries using joins and window functions to extract and aggregate transactional data from relational databases.

Python Automation: Used Python (Pandas) to clean raw data, handle missing values, and calculate key metrics like Customer Lifetime Value (CLV).

Excel Dashboards: Created dynamic Excel dashboards using Pivot Tables, XLOOKUP, and conditional formatting to visually isolate low-performing product categories.

Business Impact: Delivered actionable insights to the marketing team, helping optimize ad spend and improve seasonal retention.

Tools & Technologies (Paste this into the Tools section)
Python (Pandas), SQL, Advanced Excel, Pivot Tables, XLOOKUP, Data Cleaning, Cohort Analysis
